Mirage Raceway Leaderboard v0.6.0 - Animated FX third theme
WoW 3.3.5a / Epoch Reborn

Visual Theme cycles: Racing FX -> Illustrated FX -> Animated FX.
Animated FX uses illustrated banners with independent moving rocket, radial flashes, streaks, and sparks.
Animation Quality: FULL / REDUCED / OFF. Particle Effects and Glow & Flicker toggles apply.
Commands: /mrl, /mrl fx demo, /mrl fx boost, jump, oil, green, red, first, second, third, lose, record, stop, texturetest.
Install by fully replacing the MirageRacewayLeaderboard folder, then /reload.

Note: The addon was statically checked; visual behavior requires in-game testing.


v0.7.0: Main window /mrl with Leaderboard TOP 50 local records and My Statistics. /mrl settings opens existing options. /mrl fx demo and texturetest retained. Custom race artwork is used as the background. Portraits require available WoW unit data; otherwise a question mark is displayed.
